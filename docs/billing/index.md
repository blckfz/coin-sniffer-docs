### Screener — $29/month

Everything in the web app: real-time screener table, all 17 alert types, Discord/Telegram webhooks, watchlist, VCP/Fibonacci indicators, and all 6 timeframes. Does **not** include TradingView Pine Scripts.

### TradingView Indicators — $12/month

Access to all 7 invite-only Pine Script indicators on TradingView. Does **not** include access to the Coin Sniffer web screener app.

If you already have a TradingView Pro plan and prefer to work entirely in TradingView, this is the right choice.

### Bundle — $39/month

Screener + TradingView Indicators together. Saves $2/month vs buying separately (best value).

## Free trial details

- All features unlocked during trial (same as paid)
- No credit card required to start

Visit [coin-sniffer.com](https://coin-sniffer.com), create a free account, and choose your plan when the trial ends — or upgrade immediately from the **Billing** page in the app.
