# Dojo Zones

[Open Dojo Zones on TradingView](https://www.tradingview.com/script/ttQbeegL-Dojo-Zones/).

Dojo Zones draws areas of interest on your TradingView chart.

| Label | Meaning |
| --- | --- |
| FVG | Fair value gap |
| OB | Order block |
| BB | Breaker block |
| HOB | Hidden order block |

Use the script's display and detection controls to choose which zone types are shown. Options for retaining filled gaps and limiting displayed zones help reduce clutter; consult the installed version's settings for the available controls.

A chart with many overlapping areas can be easier to read with fewer zone types enabled. Always check the selected symbol and chart timeframe. Do not assume that one instance displays zones from every timeframe.

The script provides zone-related alert conditions. Its drawings are not automatic orders and are not the same as the entry, stop and target plan published in the web app's **Dojo Zones** tab.

This script is invite-only. See [Getting access](/tradingview/getting-access).
