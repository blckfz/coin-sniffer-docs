# Dojo Liquidity

[Open Dojo Liquidity on TradingView](https://www.tradingview.com/script/qsFFesgw-Dojo-Liquidity/).

Dojo Liquidity marks liquidity pools and labels how price interacts with them.

| Label or display | What it describes |
| --- | --- |
| BSL / SSL | Buy-side / sell-side liquidity areas |
| EQH / EQL | Equal-high / equal-low areas |
| Tap count | Recorded interactions with a pool |
| SFP | Swing-failure-pattern label |
| Failed auction / pool taken | Different classifications of price interacting with a level |
| Setup state | The script's current assessment of a developing setup |

Use the installed script's settings to control visible pools, labels and state information. Available alerts cover liquidity interactions and setup events.

An **ARMED** label belongs to this TradingView indicator's setup state. It does not mean an exchange order was placed, and it is not confirmation that a Coin-Sniffer web-app plan exists for that event.
