# Raids — existing TradingView script reference

This page is for users whose membership already includes a Raids TradingView script. It does not advertise inclusion in the current [Dojo indicator offer](/tradingview/).

**Purpose:** Potential reversals following directional price activity.

Use the installed script's description for its required chart timeframe. Its settings determine the available labels, colours and alert conditions. Do not assume that a timeframe requirement from this script applies to the Dojo indicators.

Script events can differ from web-app alerts because the chart context, settings and version can differ. They are not guaranteed to match event for event.

For the corresponding web-app alert family, see [Raids alerts](/features/alerts/raids). For missing script access or questions about inclusion in your membership, see [Getting access](/tradingview/getting-access).
