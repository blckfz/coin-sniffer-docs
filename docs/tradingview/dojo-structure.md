# Dojo Structure

[Open Dojo Structure on TradingView](https://www.tradingview.com/script/qm8ifCzF-Dojo-Structure/).

Dojo Structure labels swings and market-structure events so you can review directional context on your chart.

| Label | Meaning |
| --- | --- |
| HH / HL | Higher high / higher low |
| LH / LL | Lower high / lower low |
| BOS | Break of structure |
| CHoCH | Change of character; a potential change in the existing structure |
| Liquidity grab | A wick-only interaction distinguished from a confirmed structure break |

The bias table summarises the displayed structure. Its higher-timeframe row is available when an HTF bias timeframe is configured.

Use the settings to show or hide swing labels, break lines, liquidity-grab markers and the bias table. You can adjust colours and table position without changing the chart symbol.

Available alert conditions include directional BOS and CHoCH events and liquidity grabs. A label or alert describes an event; it does not guarantee a continuing trend or reversal.
