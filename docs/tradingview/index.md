# TradingView indicators

The current Dojo indicator offer contains three tools for use on your own TradingView charts. **All are invite-only and sold separately from the Coin-Sniffer web app.** Temporary test access is not permanent free access.

| Indicator | What you see |
| --- | --- |
| [Dojo Structure](/tradingview/dojo-structure) | Swing labels, structure breaks, liquidity-grab markers and a bias table. |
| [Dojo Zones](/tradingview/dojo-zones) | Fair value gaps, order blocks, breaker blocks and hidden order blocks. |
| [Dojo Liquidity](/tradingview/dojo-liquidity) | Liquidity pools, interaction labels and setup-state information. |

Each script offers its own display settings and alert conditions. Follow the instructions for that particular script and version. There is no blanket requirement to run all Dojo indicators on a one-minute chart.

## Web app versus TradingView

The web app monitors its covered markets and publishes alerts and Dojo plans. A TradingView script runs in the context of the chart and settings you choose. A script label is not automatically a Coin-Sniffer plan or a matching app alert.

You do not need these scripts or a TradingView account to use the web app. Purchasing an indicator does not automatically grant web app access or Pro webhook delivery.

See [Getting access](/tradingview/getting-access).

## Existing momentum-script users

Older documentation included Surge, Scout, Raids and Whale TradingView scripts. If your membership includes one of these, use its installed description and settings for the supported chart timeframe and available controls. Do not assume that the current Dojo offer includes every older script.

Existing reference links remain available: [Surge 5m](/tradingview/surge-5m), [Surge 15m](/tradingview/surge-15m), [Surge 60m](/tradingview/surge-60m), [Scout](/tradingview/scout), [Raids](/tradingview/raids) and [Whale](/tradingview/whale).
