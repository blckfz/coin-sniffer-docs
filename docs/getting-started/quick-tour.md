# Quick tour

## 1. Browse Market Coins

Open [the app](https://coin-sniffer.com/app) after activating access. **Market Coins** shows the current tracked list. Search for a symbol, sort a column, or click a star to keep a coin near the top.

The desktop table shows **Symbol, Price, Change %, P/WA and 24h Vol**. See [Screener](/features/screener) for their meanings.

## 2. Open a chart

Select a coin to show its chart beside the table on desktop. On smaller screens, details open in a mobile panel.

Charts start on **1D**. Use the timeframe buttons to change resolution, and **Alerts** to show or hide alert markers. The timeline below the chart helps you review recent activity.

## 3. Review Alert History

Switch to **Alert History** to browse recent alerts grouped by coin. Search or sort the table, then select a row to inspect the coin's chart and alert timeline.

## 4. Explore Dojo Zones

Switch to **Dojo Zones**. The default **Live** view contains **Waiting** and **Open** setups. Use **Closed** for resolved or invalidated setups, or **All** to include both.

Filter by **1D / 5D / 1W** and **Long / Short**. Select a row to expand the plan and draw its levels on the daily chart. Read [Dojo Zones](/features/dojo) before interpreting a status or outcome.

## 5. Set your notifications

Open **Settings → Alert Rules** to choose built-in alert types. Configure sound and browser notifications to suit your workflow. Browser notifications require browser permission and an open app session.

**Settings → Colors** changes alert colours. **Settings → General** includes toolbar preferences and password settings.

## 6. Arrange community delivery if needed

**Settings → Webhooks** is available with Pro access. Delivery to your own community is arranged and priced separately; contact Coin-Sniffer through Whop. See [Webhooks](/features/webhooks).
