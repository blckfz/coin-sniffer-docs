# Surge alerts

Surge alerts highlight directional momentum. **Bull** labels indicate upward activity and **Bear** labels indicate downward activity at the time of the alert.

| Label | Focus |
| --- | --- |
| Surge 5 Bull / Bear | Shorter-term momentum |
| Surge 15 Bull / Bear | Momentum over a broader short-term window |
| Surge 60 Bull / Bear | Hourly momentum |
| Surge 60 Bull / Bear V2 | An alternative hourly preset |

V2 is a separate preset, not a guarantee of higher accuracy. A Surge alert does not show whether a move has further to run.

Enable the variants you want in **Settings → Alert Rules**, then inspect their timing and subsequent price action in **Alert History** and the chart timeline.

See [Alerts](/features/alerts/) for notification controls.
