# Scout alerts

**Scout Bull** and **Scout Bear** highlight developing directional momentum. They help identify coins worth examining before deciding whether the activity fits your own analysis.

Scout is not a promise that a Surge alert will follow, or that the move will continue. There is no required Scout → Surge sequence.

Enable either direction under **Settings → Alert Rules**. Use the chart and alert timeline to see when the event occurred and what price did afterward.

See [Alerts](/features/alerts/) for notification controls.
