# Raid alerts

Raid alerts highlight potential reversals following directional price activity.

| Label | Context |
| --- | --- |
| Bottom Raid | Potential upward reversal after downward activity |
| Top Raid | Potential downward reversal after upward activity |
| Bottom Raid V2 / Top Raid V2 | Alternative reversal presets |

A Raid label does not prove that a liquidity sweep occurred or that a lasting top or bottom has formed. Inspect the chart and surrounding structure before drawing that conclusion.

The original and V2 variants have separate toggles under **Settings → Alert Rules**. A V2 label is not a confidence rating or a guaranteed improvement in results.

For the separate TradingView tool that marks liquidity pools, see [Dojo Liquidity](/tradingview/dojo-liquidity).
