# VCP reference

Earlier Coin-Sniffer documentation described VCP as a main screener column. The current **Market Coins** table shows **P/WA** instead; it does not expose a VCP column.

Do not confuse P/WA with a VCP score or assume that a generic interpretation of a similarly named indicator applies to Coin-Sniffer. P/WA describes price relative to the weighted average, not a forecast or probability.

See [Market Coins](/features/screener) for the current columns and [Charts](/features/charts) for the available chart controls.
