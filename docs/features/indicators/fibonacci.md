# Fibonacci and plan levels

Earlier documentation described an automatic Fibonacci pivot overlay on the web chart. The current main chart does not provide that overlay or a Fibonacci toggle.

To display a plan's levels, select a row in **Dojo Zones**. The chart shows that setup's zone, entry, stop and targets. Use the prices in the expanded plan; they are not a generic pivot ladder.

Changing the candle timeframe changes the chart resolution, not the selected plan's prices or timeframe.

See [Dojo Zones](/features/dojo) and [Charts](/features/charts). The separately sold [TradingView indicators](/tradingview/) have their own controls and access requirements.
